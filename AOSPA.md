# AOSPA branch

This `aospa` branch exists for the AOSPA (calcite / Android 17) port of the
Motorola fogos (moto g34 5G).

No source changes were needed in this repository for AOSPA. The branch is a
copy of the upstream tree so that `fogos.xml` can use a single revision
(`aospa`) for every project.

Upstream: https://github.com/tiraq-official/proprietary_vendor_motorola_sm6375-common (17.0)
